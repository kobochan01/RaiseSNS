# 機能定義書: アカウント

## 概要

メールアドレス＋パスワードによる会員登録・ログイン・ログアウトを行う機能。

## 入力/出力

### 会員登録

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| username | 文字列 | 必須 | ユーザー名（@handle） |
| email | 文字列（メール形式） | 必須 | メールアドレス |
| password | 文字列 | 必須 | パスワード（平文、送信はHTTPS） |
| display_name | 文字列 | 必須 | 表示名 |

**出力**

| 項目 | 説明 |
|------|------|
| id | 発行されたユーザーID |
| username | ユーザー名 |
| display_name | 表示名 |

### ログイン

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| email | 文字列（メール形式） | 必須 | メールアドレス |
| password | 文字列 | 必須 | パスワード |

**出力**

| 項目 | 説明 |
|------|------|
| セッション/トークン | ログイン状態を維持するための情報 |
| ユーザー情報 | id・username・display_name・avatar_url |

### ログアウト

**入力**: なし（ログイン中セッション/トークンを使用）
**出力**: なし（セッション/トークンの無効化）

## バリデーションルール

| 項目 | ルール |
|------|--------|
| username | 3〜30文字、英数字とアンダースコアのみ、既存ユーザーと重複不可 |
| email | メール形式、既存ユーザーと重複不可 |
| password | 8文字以上 |
| display_name | 1〜50文字 |
| ログイン | email・passwordの組み合わせが一致しない場合はエラー |
