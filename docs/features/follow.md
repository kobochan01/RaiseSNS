# 機能定義書: フォロー

## 概要

他ユーザーをフォロー・フォロー解除し、フォロー中/フォロワーの一覧を表示する機能。

## 入力/出力

### フォローする

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| followeeId（またはusername） | 数値/文字列 | 必須 | フォロー対象のユーザーID |

**出力**

| 項目 | 説明 |
|------|------|
| followerCount | フォロー後の対象ユーザーのフォロワー数 |
| isFollowedByMe | true |

### フォロー解除する

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| followeeId（またはusername） | 数値/文字列 | 必須 | フォロー解除対象のユーザーID |

**出力**

| 項目 | 説明 |
|------|------|
| followerCount | 解除後の対象ユーザーのフォロワー数 |
| isFollowedByMe | false |

### フォロー中/フォロワー一覧取得

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| userId（またはusername） | 数値/文字列 | 必須 | 対象ユーザー |
| type | 文字列（following/followers） | 必須 | フォロー中一覧かフォロワー一覧か |

**出力**

| 項目 | 説明 |
|------|------|
| users | 一覧（username・display_name・avatar_url・isFollowedByMe） |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| フォロー対象 | 自分自身をフォローすることはできない |
| 重複フォロー | 既にフォロー中のユーザーへの再フォローはエラー、または冪等に成功扱いとする（実装フェーズで決定） |
| フォロー解除 | フォローしていないユーザーへの解除操作はエラー |
| 一覧取得 | ページングで件数を制限 |
