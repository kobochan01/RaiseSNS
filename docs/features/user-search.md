# 機能定義書: ユーザー検索

## 概要

ユーザー名（@username）でユーザーを検索する機能。フォロー対象を見つけるための入口となる。

## 入力/出力

### ユーザー検索

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| keyword | 文字列 | 必須 | 検索キーワード（usernameの部分一致に使用） |

**出力**

| 項目 | 説明 |
|------|------|
| results | 該当ユーザーの一覧（username・display_name・avatar_url） |
| totalCount | 該当件数 |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| keyword | 1文字以上。空文字での検索は不可 |
| 検索方式 | username に対する部分一致（大文字小文字を区別しない） |
| 検索結果 | 新着順または関連度順（表示順は実装フェーズで決定）、ページングで件数を制限 |
