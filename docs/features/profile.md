# 機能定義書: プロフィール

## 概要

自分のプロフィール（表示名・自己紹介・アイコン画像）の編集と、自分・他ユーザーのプロフィール閲覧を行う機能。

## 入力/出力

### プロフィール編集

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| display_name | 文字列 | 必須 | 表示名 |
| bio | 文字列 | 任意 | 自己紹介 |
| avatar_image | 画像ファイル | 任意 | アイコン画像（アップロード後 avatar_url として保存） |

**出力**

| 項目 | 説明 |
|------|------|
| display_name | 更新後の表示名 |
| bio | 更新後の自己紹介 |
| avatar_url | 更新後のアイコン画像URL |

### プロフィール閲覧

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| username | 文字列 | 必須 | 閲覧対象のユーザー名 |

**出力**

| 項目 | 説明 |
|------|------|
| username / display_name / bio / avatar_url | プロフィール基本情報 |
| followerCount | フォロワー数 |
| followingCount | フォロー中数 |
| isFollowedByMe | 自分がフォロー中かどうか（他ユーザー閲覧時） |
| posts | 対象ユーザーの投稿一覧 |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| display_name | 1〜50文字、必須 |
| bio | 0〜160文字、任意 |
| avatar_image | 画像形式（jpg/png/gif等）、最大5MB |
| プロフィール編集 | 本人のみ実行可能。他ユーザーのプロフィールは編集不可 |
