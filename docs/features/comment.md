# 機能定義書: コメント

## 概要

投稿に対してコメントを作成し、自分のコメントを削除する機能。コメントには返信(ネスト)を付けられる。投稿者以外の第三者もコメント・返信できる。編集機能は持たない。

## 入力/出力

### コメント作成(返信を含む)

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| postId | 数値 | 必須 | コメント対象の投稿ID |
| body | 文字列 | 必須 | コメント本文 |
| parentCommentId | 数値 | 任意 | 返信元のコメントID。指定しない場合はトップレベルコメントになる |

**出力**

| 項目 | 説明 |
|------|------|
| id | 発行されたコメントID |
| body / author / parentCommentId / created_at | 作成されたコメントの内容 |
| replies | 返信一覧(作成直後は空配列) |

### コメント一覧取得

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| postId | 数値 | 必須 | コメント対象の投稿ID |

**出力**

| 項目 | 説明 |
|------|------|
| コメントの配列 | トップレベルコメントを配列で返す。各コメントは `replies` に自身への返信をネストして含む(無制限の階層に対応) |

### コメント削除

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| commentId | 数値 | 必須 | 削除対象のコメントID |

**出力**

| 項目 | 説明 |
|------|------|
| commentCount | 更新後の投稿のコメント数 |

> 返信付きのコメントを削除した場合、その返信もすべて連動して削除される。`commentCount` は削除後の実際の件数を再集計して返す(クライアント側での差分計算に依存しない)。

## バリデーションルール

| 項目 | ルール |
|------|--------|
| body | 1〜140文字、必須 |
| コメント作成 | ログイン中のユーザーであれば誰でも可能(投稿者本人でも可) |
| 返信 | parentCommentIdに指定できるのは同一投稿に属するコメントのみ |
| コメント削除 | コメントの作成者本人のみ実行可能 |
