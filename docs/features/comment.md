# 機能定義書: コメント

## 概要

投稿に対してコメントを作成し、自分のコメントを編集・削除する機能。投稿者以外の第三者もコメントできる。

## 入力/出力

### コメント作成

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| postId | 数値 | 必須 | コメント対象の投稿ID |
| body | 文字列 | 必須 | コメント本文 |

**出力**

| 項目 | 説明 |
|------|------|
| id | 発行されたコメントID |
| body / author / created_at | 作成されたコメントの内容 |
| commentCount | 更新後の投稿のコメント数 |

### コメント編集

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| commentId | 数値 | 必須 | 編集対象のコメントID |
| body | 文字列 | 必須 | 更新後の本文 |

**出力**

| 項目 | 説明 |
|------|------|
| body / updated_at | 更新後の内容 |

### コメント削除

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| commentId | 数値 | 必須 | 削除対象のコメントID |

**出力**

| 項目 | 説明 |
|------|------|
| commentCount | 更新後の投稿のコメント数 |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| body | 1〜140文字、必須 |
| コメント作成 | ログイン中のユーザーであれば誰でも可能（投稿者本人でも可） |
| コメント編集・削除 | コメントの作成者本人のみ実行可能 |
