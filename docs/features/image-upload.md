# 機能定義書: 画像投稿

## 概要

投稿に添付する画像、およびプロフィールのアイコン画像をAWS S3にアップロードする機能。

## 入力/出力

### 画像アップロード

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| image | 画像ファイル（multipart/form-data） | 必須 | アップロードする画像 |

**出力**

| 項目 | 説明 |
|------|------|
| image_url | S3上に保存された画像のURL |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| ファイル形式 | jpg / jpeg / png / gif / webp のみ許可 |
| ファイルサイズ | 最大5MB |
| 保存先 | AWS S3（`posts/` `avatars/` でパスを分け、ファイル名はUUIDで採番） |
| アクセス方式 | 公開URL（署名なし）で配信。S3バケット側で `posts/*`・`avatars/*` への `s3:GetObject` を公開許可する |
| アップロード失敗時 | 投稿・プロフィール更新自体は失敗させ、部分的な保存状態を残さない。実装上は「先に画像アップロードAPIを呼びURLを取得し、そのURLを投稿作成・プロフィール更新APIに渡す」二段階方式とし、アップロードに失敗した場合は後続のAPIを呼ばないことで保証する |

## API

| メソッド | パス | 説明 |
|---------|------|------|
| POST | `/api/images/posts` | 投稿画像をアップロードし `image_url` を返す |
| POST | `/api/images/avatars` | プロフィールアイコン画像をアップロードし `image_url` を返す |
