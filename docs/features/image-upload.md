# 機能定義書: 画像投稿

## 概要

投稿に添付する画像、およびプロフィールのアイコン画像をAWS S3にアップロードする機能。

## 入力/出力

### 画像アップロード

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| image | 画像ファイル（multipart/form-data） | 必須 | アップロードする画像 |

**出力**

| 項目 | 説明 |
|------|------|
| image_url | S3上に保存された画像のURL |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| ファイル形式 | jpg / jpeg / png / gif / webp のみ許可 |
| ファイルサイズ | 最大5MB |
| 保存先 | AWS S3（バケットは投稿用・アイコン用でパスを分ける） |
| アクセス方式 | 公開URL、または署名付きURLで配信（実装フェーズで決定） |
| アップロード失敗時 | 投稿・プロフィール更新自体は失敗させ、部分的な保存状態を残さない |
