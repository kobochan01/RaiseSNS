# 機能定義書: いいね

## 概要

投稿に対していいねを付け外しする機能。投稿者以外の第三者もいいねできる。

## 入力/出力

### いいねする

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| postId | 数値 | 必須 | いいね対象の投稿ID |

**出力**

| 項目 | 説明 |
|------|------|
| likeCount | いいね後の投稿のいいね数 |
| isLikedByMe | true |

### いいね解除する

**入力**

| 項目 | 型/形式 | 必須 | 説明 |
|------|---------|------|------|
| postId | 数値 | 必須 | いいね解除対象の投稿ID |

**出力**

| 項目 | 説明 |
|------|------|
| likeCount | 解除後の投稿のいいね数 |
| isLikedByMe | false |

## バリデーションルール

| 項目 | ルール |
|------|--------|
| いいね | 同一ユーザーが同一投稿に対して二重にいいねすることはできない（`(post_id, user_id)` のユニーク制約） |
| いいね解除 | いいねしていない投稿への解除操作はエラー、または冪等に成功扱いとする（実装フェーズで決定） |
| いいね対象 | 自分の投稿にも、いいね可能 |
