# 要件定義

## 目的

X（旧Twitter）のタイムライン形式を模した SNS 風アプリを学習目的で開発する。受講生や個人が利用する想定だが、複数ユーザーが同時に使うことを前提に設計し、投稿・コメント・いいねが第三者からも行われる SNS らしい体験を実現する。

## ユーザーストーリー

- ユーザーとして、メールアドレスとパスワードで会員登録・ログインできる。なぜなら自分専用の投稿・フォロー関係を管理したいから。
- ユーザーとして、テキストと画像を投稿できる。なぜなら日々の出来事や写真を共有したいから。
- ユーザーとして、全ユーザーの投稿が新着順に並ぶタイムラインを見られる。なぜなら知らないユーザーの投稿にも触れたいから。
- ユーザーとして、フォローしているユーザーの投稿だけのタイムラインを見られる。なぜなら関心のある相手の投稿を追いたいから。
- ユーザーとして、他ユーザーをフォロー・フォロー解除できる。なぜなら見たい投稿の範囲を自分で選びたいから。
- ユーザーとして、他人の投稿にコメントできる。なぜなら投稿者や他の閲覧者と交流したいから。
- ユーザーとして、投稿やコメントについたいいね数・コメント数を確認できる。なぜなら第三者からの反応の大きさを知りたいから。
- ユーザーとして、他人の投稿にいいねを付けたり外したりできる。なぜなら気軽に反応を示したいから。
- ユーザーとして、自分の投稿・コメントを編集・削除できる。なぜなら誤字や投稿の取り消しに対応したいから。
- ユーザーとして、自分のプロフィール（表示名・自己紹介・アイコン画像）を編集できる。なぜなら自分がどんなユーザーかを他者に伝えたいから。

## 機能要件

| # | 機能 | 説明 | 優先度 |
|---|---|---|---|
| 1 | 会員登録・ログイン・ログアウト | メールアドレス＋パスワードによる自前認証 | 高 |
| 2 | 全体タイムライン表示 | 全ユーザーの投稿を新着順に一覧表示 | 高 |
| 3 | フォロー中タイムライン表示 | フォローしているユーザーの投稿のみを新着順に一覧表示 | 高 |
| 4 | フォロー／フォロー解除 | 他ユーザーをフォロー・フォロー解除できる | 高 |
| 5 | 投稿作成 | テキスト（必須）と画像（任意）を投稿できる | 高 |
| 6 | 投稿編集・削除 | 自分の投稿のみ編集・削除できる | 中 |
| 7 | コメント作成・編集・削除 | 投稿に対して誰でもコメントでき、自分のコメントのみ編集・削除できる。投稿にはコメント数を表示する | 高 |
| 8 | いいね・いいね解除 | 投稿に対して誰でもいいねを付け外しできる。投稿にはいいね数を表示する | 高 |
| 9 | 画像投稿 | 投稿に添付した画像をクラウドストレージ（S3等）に保存する | 高 |
| 10 | プロフィール編集 | 表示名・自己紹介・アイコン画像を編集できる | 中 |
| 11 | プロフィール閲覧 | 自分・他ユーザーのプロフィールと、フォロー数・フォロワー数を閲覧できる | 中 |

### 差別化要素（Xとの違い）

- インプレッション数（閲覧数）は表示しない。
- リツイート（リポスト）機能は搭載しない。

## 非機能要件

| 項目 | 内容 |
|---|---|
| パフォーマンス | 学習目的のアプリのため厳密な性能要件は設けない。タイムライン表示はページング等で一覧取得件数を制限する |
| セキュリティ | パスワードはハッシュ化して保存する。投稿・コメントの編集/削除は本人のみ許可する認可チェックを行う。画像アップロードはファイル形式・サイズを制限する |
| 対応環境 | PC・モバイルブラウザ（レスポンシブ対応） |
