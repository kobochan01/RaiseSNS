# 要件定義書

## 1. プロジェクト背景・目的

本プロジェクトは学習目的で作成するWebアプリケーションである。
X（旧Twitter）風のタイムライン形式SNSを自力で設計・実装することを通じて、以下の学習を目的とする。

- Reactを用いたコンポーネント設計とstate管理の習得
- Spring Boot + PostgreSQLを用いたサーバーサイドのデータ永続化・認証の理解
- クラウドストレージ（S3等）を用いた画像アップロードの実装経験
- 複数ユーザーが交流するアプリにおけるリレーション設計（フォロー・いいね・コメント）の理解
- 要件定義から実装までの開発プロセスの体験

## 3. 非機能要件

### 対応環境
- PC・モバイルブラウザ（レスポンシブ対応）

### 性能要件
- 学習目的のアプリのため厳密な性能要件は設けない
- タイムライン表示はページング等で一覧取得件数を制限する

### セキュリティ
- パスワードはハッシュ化して保存する
- 投稿・コメントの編集/削除は本人のみ許可する認可チェックを行う
- 画像アップロードはファイル形式・サイズを制限する
- ユーザー入力値をそのままHTMLに埋め込まない（ReactのデフォルトエスケープによりXSSを防ぐ）
- SQLインジェクション対策はSpring Data JPA（プリペアドステートメント）により対応する
