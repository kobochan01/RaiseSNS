# RaiseSNS プロトタイプモック

`docs/`の要件定義・機能定義・画面設計に基づいて作成した、**バックエンド・データベースを使わない静的HTML/CSS/JavaScriptのプロトタイプ**です。本実装（React + Spring Boot + PostgreSQL）に入る前に、画面遷移や操作感を確認するためのモックです。

## 起動方法

ビルド不要です。以下のいずれかの方法で開いてください。

- `mock/index.html` をブラウザで直接ダブルクリックして開く
- または、簡易HTTPサーバーで起動する（推奨）

```powershell
cd mock
npx serve .
# もしくは
python -m http.server 8000
```

## データの保存について

- ユーザー・投稿・コメント・いいね・フォロー関係はすべてブラウザの`localStorage`に保存されます。ページをリロードしてもデータは保持されます。
- 投稿・アイコン画像はBase64形式でそのまま保存されます（実際のアップロード・S3連携は行いません）。大きな画像を何枚も貼り付けると`localStorage`の容量上限（ブラウザにより5〜10MB程度）に達する場合があります。
- データを初期状態に戻したい場合は、ブラウザの開発者ツールで `localStorage.clear()` を実行するか、サイトデータを削除してください。

## 対象外（実装しないこと）

- パスワードのハッシュ化・実際の認証セッション
- 画像の実アップロード・AWS S3連携
- ページング（一覧は全件表示）
- サーバーとの通信（すべてJS内で完結）
